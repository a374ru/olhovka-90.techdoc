Настройка сервера

Установка локального сервера Ubuntu на Mac mini 2010

Подробная пошаговая инструкция.

Первая часть посвящена чистой установке Linux Ubuntu Server на ваш Mac mini 2010 (с учетом клавиатуры Windows и особенностей старых компьютеров Apple), а вторая часть — развертыванию Portainer и правильной подготовке системы.

Часть 1.

Установка Ubuntu Server на Mac mini 2010

Так как стандартная комбинация Alt при включении на клавиатурах Windows не всегда срабатывает на старых компьютерах Mac, мы используем альтернативный и самый надежный метод вызова загрузочного меню.

Шаг 1.

Подготовка загрузочной флешки

Скачайте официальный ISO-образ Ubuntu Server LTS (x64) (архитектура Intel/AMD 64-bit). Скачайте и установите бесплатную программу BalenaEtcher. Вставьте флешку (минимум на 4 ГБ), откройте BalenaEtcher, выберите скачанный ISO-образ, вашу флешку и нажмите Flash.

Шаг 2.

Запуск Mac mini с флешки (через режим восстановления)

Если при обычной перезагрузке с зажатой клавишей Alt (Option) появляется черный экран или Mac его игнорирует:Полностью выключите Mac mini. Включите его и сразу зажмите комбинацию Ctrl + R (аналог Cmd + R на Windows-клавиатуре). Держите, пока не появится логотип Apple или индикатор загрузки — Mac зайдет в Режим восстановления (Recovery Mode). В верхнем меню выберите Утилиты -> Терминал.Введите команду, которая принудительно заставит Mac при следующей загрузке искать внешние накопители:

nvram boot-args="reboot=pci"

Вставьте подготовленную флешку с Ubuntu в USB-порт Mac mini. Перезагрузите компьютер, зажав и удерживая клавишу Alt на клавиатуре. Теперь на экране гарантированно появится меню выбора дисков. Выберите желтый значок диска с надписью EFI Boot.

Шаг 3.

Процесс установки Ubuntu Server

После запуска установщика следуйте подсказкам на экране: Язык и раскладка: Выберите английский English — это стандарт для серверов, чтобы избежать проблем с кодировкой в консоли. Сеть Network: Подключите Mac mini кабелем к роутеру (так надежнее). Установщик автоматически получит IP-адрес по DHCP. Настройка разметки диска (Storage Configuration): Выберите Use an entire disk (Использовать весь диск). Если внутри Mac mini два диска, выберите тот, который планируете сделать системным (например, sda).

КРИТИЧЕСКИЙ МОМЕНТ: Снимите галочку с пункта Set up this disk as an LVM group. Если оставить LVM по умолчанию, Ubuntu заберет под систему только 100 ГБ, а остальные 200 ГБ останутся неразмеченными. Отключение LVM заставит систему сразу занять все 300 ГБ под нужды сервера.

Профиль пользователя (Profile Setup):

Your server’s name:

введите имя вашего сервера (например, YSTM-SERVER). Pick a username / Password: создайте свою учетную запись администратора и надежный пароль.

SSH Setup:

Обязательно отметьте галочкой пункт Install OpenSSH server. Это позволит вам управлять Mac mini удаленно с вашего основного компьютера.Featured Server Snaps: Ничего не выбирайте, просто нажмите Done. Дождитесь окончания процесса (появится надпись Installation complete) и нажмите Reboot Now. Извлеките флешку, когда система попросит об этом.

Часть 2.

Настройка Docker и Portainer на сервере.

После перезагрузки Mac mini начнет работать в режиме консоли. Теперь вы можете пересесть за ваш основной рабочий компьютер, открыть Терминал (на Mac) или Командную строку (на Windows) и подключиться к серверу удаленно c вашим паролем и IP-адресом сервера:

ssh   your_login@ip_adress

Далее терминал предложит ввести пароль, который был установлен в настройках сервера. Если пароль правильный, тогда вы перейдёте на диск сервера.

Шаг 1.

Обновление системы и подготовка папок перед установкой Docker

Обновим пакеты и сразу создадим физическую папку, где в будущем ваши камеры Aqara будут хранить видеофайлы:

sudo apt update && sudo apt upgrade -y
sudo mkdir -p /home/video_storage
sudo chmod -R 777 /home/video_storage

Шаг 2.

Автоматическая установка Docker

Установим официальный движок Docker одной командой:

curl -fsSL https://docker.com -o get-docker.sh && sudo sh get-docker.sh

Добавим вашего пользователя в группу Docker, чтобы управлять контейнерами без постоянного ввода sudo:

sudo usermod -aG docker $USER

Чтобы изменения групп вступили в силу, переподключитесь к серверу по SSH (exit, а затем снова команда ssh …).

Шаг 3.

Установка и запуск Portainer

Для хранения настроек самого Portainer создадим для него изолированный том в Docker:

docker volume create portainer_data

Теперь запустим контейнер Portainer Community Edition:

docker run -d -p 8000:8000 -p 9443:9443 -p 9000:9000 --name portainer --restart always -v /var/run/docker.sock:/var/run/docker.sock -v portainer_data:/var/io/portainer_data portainer/portainer-ce:latest

Шаг 4.

Первый вход в Portainer

Откройте браузер на вашем компьютере и перейдите по адресу: http://ip_адрес_сервера:9000 например:

  • http://192.168.1.157:9000

При первом входе система попросит вас создать пароль администратора (минимальная длина — 12 символов). После создания пароля выберите среду Get Started (локальное окружение Docker). Перед вами откроется Dashboard (панель управления), где в разделе Stacks вы сможете развернуть конфигурацию файлового хранилища Samba для вашей камеры Aqara G5 Pro и Mac, которую мы успешно настроили ранее.Попробовать без персонализацииКакие настройки требуется внести для корректной работы smb? Для того чтобы Samba-сервер SMB, запущенный в Docker через Portainer на вашем Mac mini, работал максимально корректно, быстро и без сбоев одновременно и с компьютерами Apple macOS, и с умными камерами Aqara G5 Pro, необходимо учесть ряд специфических настроек. Ниже приведен полный чек-лист настроек — от конфигурации самого контейнера до параметров Linux-системы и роутера.

1. Настройки внутри Portainer Docker Compose

Ваш итоговый стек в Portainer должен содержать правильный баланс между поддержкой старого протокола поиска для камеры и защитой от дублирования дисков для Mac. Используйте только один порт для данных: Для передачи файлов должен быть открыт только современный порт 445:445. . Порты обнаружения UDP: Камера Aqara ищет сервер по портам 137:137/udp и 138:138/udp. Они обязательны для автопоиска в приложении. Отключение фантомных дисков через переменные: В блоке environment переменная NMBD=true должна работать в паре с флагом command: -w “WORKGROUP” -g “netbios name = YSTM-SERVER”. Это жестко связывает NetBIOS-имя и рабочую группу, помогая камере увидеть NAS. Финальный эталонный YAML-код для Portainer:

version: '3.8'

services:
  samba:
    image: dperson/samba
    container_name: samba_storage
    restart: unless-stopped
    ports:
      - "445:445"
      - "137:137/udp"     # <--- Порты для обнаружения
      - "138:138/udp"     # <--- камерой Aqara
      - "139:139"         # <--- в локальной сети
    environment:
      - TZ=Europe/Moscow
      - PERMISSIONS=true
      - NMBD=true         # <--- Включаем службу сетевых имён NetBIOS
      - NMBD=false
      - RESTART=smbd
      - USER=ystm;ystm
      - SHARE=video;/mount;yes;no;no;ystm
    command: -w "WORKGROUP" -g "netbios name = YSTM-SERVER"
    volumes:
      - /opt/ystm_cameras:/mount

2. Настройки на уровне Ubuntu Server

Сетевой протокол SMB очень чувствителен к правам доступа внутри Linux. Контейнер не сможет записать видеопоток, если ОС Ubuntu заблокирует доступ к жесткому диску. Полноценные права на папку (Права 777): Так как Docker запускает службы от виртуальных пользователей, физическая папка на Mac mini должна быть открыта для записи:

sudo chmod -R 777 /home/video_storage

Служба mDNS (Avahi) для Apple-устройств: Чтобы Mac всегда находил сервер по адресу smb://YSTM-SERVER.local, на самом Linux-сервере должна быть активна служба Bonjour/Avahi. Убедитесь, что она запущена:

sudo apt install -y avahi-daemon
sudo systemctl enable avahi-daemon
sudo systemctl start avahi-daemon

3. Настройки на стороне Роутера.

Поскольку SMB-сервер обслуживает беспроводное устройство Wi-Fi камеру и проводной сервер Mac mini, настройки роутера играют ключевую роль. Фиксация IP-адреса (Статический IP): В панели роутера (192.168.1.1) в разделе «Домашняя сеть» найдите ваш Mac mini и зарегистрируйте его, закрепив за ним постоянный IP (например, 192.168.1.157). Если роутер сменит IP сервера после перезагрузки, камера Aqara потеряет архив.

Отключение изоляции беспроводных клиентов (Isolation / Guest Network):

Камера должна находиться в основной домашней Wi-Fi сети. Если подключить её к «Гостевой сети», роутер заблокирует прохождение SMB/NetBIOS пакетов до Mac mini, и автопоиск работать не будет.

Проводное подключение сервера:

Крайне рекомендуется подключать Mac mini к роутеру только по сетевому кабелю LAN, а не по Wi-Fi. Видеопоток от камер и одновременное чтение тяжелых файлов с Mac создают высокую нагрузку на сеть, с которой старый беспроводной модуль Mac mini 2010 года просто не справится (будут просадки по скорости и обрывы связи).

4. Настройки кэша на стороне macOS (Ввод паролей)

Чтобы Finder не выдавал ошибку «Сервер недоступен» после того, как Mac mini уходил в спящий режим или перезагружался:

При подключении через Finder -> Cmd + K вводите адрес со спецификатором протокола и полным путем: smb://YSTM-SERVER.local. При вводе логина обязательно отмечайте галочку «Запомнить этот пароль в связке ключей». Это позволит macOS автоматически монтировать видеоархив в фоне при каждом включении компьютера.
